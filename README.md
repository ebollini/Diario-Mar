# Diario MAR

Diario giornaliero di telefonate, email, WhatsApp e follow-up.

- **App Android**: scarica `DiarioMAR.apk` dall'ultima versione in *Releases* e installala sul telefono.
- **Diario per PC**: https://ebollini.github.io/diario-mar/

Il codice non contiene dati né password: i dati stanno nel progetto Firebase personale, accessibile solo con login.
